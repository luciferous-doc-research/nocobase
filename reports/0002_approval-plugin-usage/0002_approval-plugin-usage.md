## 調査サマリー

### 承認プラグインとは

NocoBase の承認プラグイン（`@nocobase/plugin-workflow-approval`）は、人手による承認・却下・差し戻しの決定を要するビジネスプロセスを管理するシステムです。休暇申請、経費精算承認、購買申請など、オフィスオートメーション関連のプロセスに対応しています。

### 具体的な使い方

**ワークフロー作成の流れ：**

1. ワークフロー管理ページで「Approval」タイプを選択してワークフロー作成
2. トリガー設定：承認対象となるコレクションを選択し、申請フォームを設定
3. 承認ノード追加：承認者、承認方式（全員承認/或る人が承認/投票）、処理順序（並行/順次）などを設定
4. 承認者インターフェース設定：承認者が見る UI をカスタマイズ（詳細表示、承認/却下ボタンなど）
5. ワークフローを有効化

### 承認依頼の投げ方（申請方法）

**UI 経由：**
- コレクションのデータ作成/編集フォームの「送信」ボタンに承認ワークフローをバインド
- ユーザーが送信時に自動的に承認ワークフローがトリガー
- または、承認センターから直接申請

**API 経由：**
- `POST /api/posts:create?triggerWorkflows=workflowKey` - コレクション API から申請
- `POST /api/approvals:create` - 承認センター API から申請（collectionName、workflowId、data、status パラメータを指定）

### 投げられた依頼の確認場所

**To-Do Center**（画面上部のツールバー）：

- **My Submissions**：自分が申請した承認案件の一覧と進捗
- **My To-dos**：自分に割り当てられた承認タスク（処理が必要な案件）

各セクションではカード表示をカスタマイズでき、業務フィールドや承認関連情報を自由に表示可能。
